---

### 2. Live Hosting Deployment Options

#### Option A: Hostinger Web Hosting (Built-in Git Deployment)
If your domain `schoolofawakenedpolitics.org` is hosted on Hostinger:
1. Open **Hostinger hPanel** → Go to **Websites** → Select `schoolofawakenedpolitics.org`.
2. In the sidebar, navigate to **Advanced** → **Git**.
3. Under **Create a New Repository**:
   - Repository: `https://github.com/<your-username>/<your-repo-name>.git`
   - Branch: `main`
   - Install Directory: leave default or `public_html`
4. Click **Create**.
5. Copy the **Auto Deployment Webhook URL** generated by Hostinger.
6. In your GitHub repository:
   - Go to **Settings** → **Webhooks** → **Add Webhook**.
   - Paste the Hostinger URL in **Payload URL**.
   - Content type: `application/json`.
   - Click **Add Webhook**.
*Result:* Every `git push` to `main` instantly publishes the newest version to your live website.

#### Option B: Cloudflare Pages / Vercel (Edge CDN — Recommended)
1. Sign up/log in to **Cloudflare Pages** or **Vercel**.
2. Click **Add New Project** → Import your GitHub repository.
3. Framework preset: **Astro** (Build command: `npm run build`, Output directory: `dist`).
4. Click **Deploy**.
5. In your Hostinger DNS zone, point `schoolofawakenedpolitics.org` to the provided CNAME / IP address.
*Result:* Ultra-low latency worldwide, automatic SSL, 100% free tier hosting, and instant rollback support.
